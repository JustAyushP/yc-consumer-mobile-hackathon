# yc-consumer-mobile-hackathon

Expo (Expo Router + TypeScript) mobile app backed by Convex. Built for the YC consumer mobile hackathon.

## Getting started

```bash
npm install
npx expo start   # run the app (Expo Router, routes in src/app/)
npm run dev      # convex dev: needs a Convex login/deployment (not set up yet)
```

Copy `.env.example` to `.env` and set `EXPO_PUBLIC_CONVEX_URL` once a Convex deployment exists.

Checks: `npx tsc --noEmit`, `npx expo lint`, `npx expo-doctor`. `expo-env.d.ts` is generated by `npx expo start` and is gitignored; the typecheck needs it.

Agent guidance lives in `AGENTS.md` / `CLAUDE.md`. Convex rules are in `convex/_generated/ai/guidelines.md` and Convex skills in `.agents/skills`.
